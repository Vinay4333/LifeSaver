# LifeSaver

Personal Android porn blocker for one phone. Raises the cost of an impulsive bypass. Not impossible to remove.

**Status:** M0 and M1 are in the debug build. The app installs on the emulator, starts a DNS sinkhole VPN, and blocks a tiny hardcoded list. Later milestones are in [docs/PLAN.md](docs/PLAN.md). Read [CLAUDE.md](CLAUDE.md) first.
