# M4 verification: protected status UI

Emulator `emulator-5554`, debug build, 2026-10-12. No physical device.

| State | How reached | Result |
| --- | --- | --- |
| Protection is down | Launch with VPN off, consent held | Red card, "Turn on protection" button, no Stop. Verified. |
| Protected | Tap "Turn on protection" | Green card, "Stop (debug)" shown. Verified. |
| Protected after rotation | Landscape then portrait | Same state. Verified. |
| Waiting for VPN permission | `appops set app.lifesaver ACTIVATE_VPN deny`, relaunch (emulator only; restored afterwards) | "Allow VPN and turn on" button. Verified. |
| Starting / Error | Mapped in unit tests (`ProtectionStateTest`) | Not driven on the emulator. |
| Hardened build hides Stop | `debug` is `FLAG_DEBUGGABLE`; release build not installed | **Unverified.** |

The read-only settings block shows the 48-hour cooldown (not active until M5) and the list version. There is no control that turns protection off outside the debug-only Stop button.
